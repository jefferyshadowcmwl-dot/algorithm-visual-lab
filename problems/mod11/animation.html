n 被 11 除的余数

交替和法 —— 从个位起编号，偶数号位取 +、奇数号位取 −， 得到的 diff 与 n 同余，故 答案 = diff mod 11

预设：
plus（偶数号位之和） 0
minus（奇数号位之和） 0
diff = plus − minus 0
答案 diff mod 11 –
点「下一步」开始逐位扫描，也可以直接按「自动播放」。 卡片上方标着该位取 + 还是 −，扫描时下方三个累计值会实时更新。
为什么符号会逐位交替？
因为 10 = 11 − 1 ≡ −1 (mod 11)，于是 10^k ≡ (−1)^k (mod 11)。
把 n 按位展开 n = Σ d_k · 10^k（k 从个位起编号 0），逐项取模即得 n ≡ Σ d_k · (−1)^k (mod 11)。
看 10 的幂对 11 取余：k=0,1,2,3,… 依次是 1, 10, 1, 10, …，写成带符号的形式就是 1, −1, 1, −1, … —— 只有两种取值，所以符号逐位交替，与数字本身无关。
注意负数：diff 可能是负的，而 C 与 JavaScript 的 % 对负数返回负值 （−1 % 11 === −1），必须写成 ((diff % 11) + 11) % 11； Python 的 % 则直接给出 10。锚定用例 10（diff = −1）专抓这一步。
